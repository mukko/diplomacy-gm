## 1. プレイヤー・列強・勝利条件

| ID | ルール |
|----|--------|
| R-GEN-01 | 標準ゲームは **7人**。各プレイヤーは列強を1つ担当する: **オーストリア**（オーストリア＝ハンガリー）、**イギリス**、**フランス**、**ドイツ**、**イタリア**、**ロシア**、**トルコ**。ルール中の「国 (country)」は列強を指す。 |
| R-GEN-02 | 担当列強はランダムに決める。これがゲーム中**唯一**の偶然要素である。 |
| R-GEN-03 | **勝利:** **補給都市を18以上**（全34）支配した列強が勝利する。判定は**秋ターンの後**（秋の撤退後、支配権の更新時）に行う。 |
| R-GEN-04 | **引き分け:** プレイヤーの合意でいつでもゲームを終了できる。その時点で盤上にユニットを持つ全列強が等しく引き分けとなる。 |
| R-GEN-05 | 交渉は自由形式で**拘束力はない**。外交中の発言や文書はプレイヤーを何ら拘束しない。（本ツールは状態と命令を記録するが、合意の履行を強制しない。） |

## 2. ユニット

| ID | ルール |
|----|--------|
| R-UNIT-01 | ユニットは **陸軍 (A)** と **艦隊 (F)** の2種類。 |
| R-UNIT-02 | **全ユニットの戦力は等しく 1。** 戦力は支援によってのみ増える。 |
| R-UNIT-03 | **1つの地域に同時に存在できるユニットは最大1つ。** 例外はない。 |
| R-UNIT-04 | 列強が持てるユニット数は、直前の秋ターン終了時に支配していた補給都市数に等しい（調整フェイズで適用）。したがって盤上のユニットは34を超えない。 |
| R-UNIT-05 | 物理的な駒数の制限はソフトウェアでは無関係（ルールブックは脱落国の駒の流用を認めている）。 |

## 3. 盤面

地域データの詳細は [map.md](map.md) を参照。

| ID | ルール |
|----|--------|
| R-MAP-01 | 地域は3種類: **内陸地域**（海に接しない陸地）、**海域**、**沿岸地域**（1つ以上の海域に接する陸地）。 |
| R-MAP-02 | 陸軍は内陸・沿岸地域に、艦隊は海域・沿岸地域に存在できる。 |
| R-MAP-03 | 内陸・沿岸地域のうち **34** が **補給都市** (SC)。うち22が各列強の本国補給都市、12が開始時中立。 |
| R-MAP-04 | 名前のない場所は占有できない。**スイスは通行不能**。島（グレートブリテン島を除く）は占有できない。 |
| R-MAP-05 | **艦隊の沿岸移動:** 沿岸地域にいる艦隊が隣接する沿岸地域に移動できるのは、**両地域が海岸線を共有している場合のみ**（海岸沿いに航行できる場合）。例: F ローマはトスカナ・ナポリ・ティレニア海へは移動できるが、ヴェネツィア・アプリアへは移動**できない**（陸の境界しか共有していないため）。 |
| R-MAP-06 | **分割海岸:** **ブルガリア（東岸/南岸）**、**スペイン（北岸/南岸）**、**サンクトペテルブルク（北岸/南岸）** は海岸が2つある。艦隊はどちらか一方の海岸にのみ存在し、その海岸に隣接する地域にしか移動できないが、地域全体を占有している（他ユニットを阻む）。 |
| R-MAP-07 | 艦隊が分割海岸の地域へ移動する際、**両方の海岸に到達可能な場合は海岸を指定しなければならない**。指定がなければ命令は無効となり艦隊は維持する。（一方の海岸にしか到達できない場合は海岸が自明 — プロジェクト裁定 PR-04 参照。） |
| R-MAP-08 | **キールとコンスタンティノープル**は水路が貫いており、海岸は**1つ**とみなす。艦隊は通過できる（例: オランダ→キール、次のターンにキール→ベルリン。黒海→コンスタンティノープル、次にコンスタンティノープル→エーゲ海）。陸軍は水路を自由に渡れる。ただし1ターンに1地域であり、飛び越えはできない。 |
| R-MAP-09 | **デンマーク／スウェーデン:** スウェーデンとデンマークの間は直接移動できる。艦隊は**バルト海とスカゲラク海峡の間を直接移動できず**、スウェーデンかデンマークを経由する。スウェーデンの海岸は1つ。**デンマークはベルリンと接していない。** |

## 4. ターン構成

| ID | ルール |
|----|--------|
| R-TURN-01 | ゲームは **1901年春** に始まる。各年は**春**ターンと**秋**ターンからなり、それぞれ半年を表す。 |
| R-TURN-02 | **春ターンのフェイズ:** 1. 外交 → 2. 命令記述 → 3. 命令解決 → 4. 撤退・解散。 |
| R-TURN-03 | **秋ターンのフェイズ:** 上記4つに加え、5. **増減（調整）**。 |
| R-TURN-04 | 秋ターン（撤退を含む）の後、補給都市の支配権を更新し、勝利条件（R-GEN-03）を判定し、その後に調整を行う。 |
| R-TURN-05 | 推奨交渉時間: 最初のターン前は30分、以降は15分（全員合意で短縮可）。命令記述は5分程度まで。命令の記述・読み上げ中、撤退、調整の間は**外交禁止**。（本ツールにタイマーは設けず、時間管理は GM がツールの外で行う。プロジェクトオーナー決定。） |
| R-TURN-06 | 命令には `1901年春`、`1901年秋`、`1902年春` … の日付を付ける。 |

本プロジェクトのフェイズ ID: `S1901M`（春・移動）、`S1901R`（春・撤退）、`F1901M`、`F1901R`、
`W1901A`（1901年秋の後の調整）。[architecture.md](architecture.md) 参照。

## 5. 命令 — 共通

| ID | ルール |
|----|--------|
| R-ORD-01 | 命令は**秘密裏に**書き、**同時に**公開する。 |
| R-ORD-02 | 各列強は自軍ユニットの全部・一部・どれにも命令しなくてもよい。各ユニットは **維持・移動・支援・輸送**（輸送は艦隊のみ）のうち1つだけを受ける。 |
| R-ORD-03 | **命令のないユニットは維持する。** |
| R-ORD-04 | **不正な命令は実行されず、ユニットは維持する。**（維持支援は受けられる。） |
| R-ORD-05 | **合法な**命令は書き間違いであっても実行しなければならない。書き方が拙くても意味が一通りしかない命令はその意味で実行する。 |
| R-ORD-06 | 記法: ユニット種別・地域・命令。種別（A/F）は確認用であり、省略しても命令は無効にならない（1地域に1ユニットしか存在しないため）。略称は [map.md](map.md) 参照。 |

記法まとめ:

| 命令 | 記法 | 例 |
|------|------|-----|
| 維持 | `<U> <地域> H` / `Holds` | `F Lon H` |
| 移動 | `<U> <出発>-<到着>` | `A Par-Bur`, `F Con-Bul EC` |
| 維持支援 | `<U> <地域> S <U> <地域>` | `F Den S F Bal` |
| 移動支援 | `<U> <地域> S <U> <出発>-<到着>` | `A Par S A Mar-Bur` |
| 輸送 | `F <海域> C A <出発>-<到着>` | `F Bla C A Ank-Sev` |
| 撤退 | `<U> <出発>-<到着>` | `A Bur-Gas` |
| 解散 | `<U> <地域> D` | `A Gal D` |
| 建設 | `B <U> <地域>[ <海岸>]` | `B F StP NC` |

## 7. 移動

| ID | ルール |
|----|--------|
| R-MOV-01 | **陸軍**は隣接する内陸・沿岸地域へ移動できる。海域へは移動できない（輸送を除く。§9）。 |
| R-MOV-02 | **艦隊**は隣接する海域、または海岸線を共有する隣接沿岸地域へ移動できる（R-MAP-05/06）。内陸へは不可。 |
| R-MOV-03 | 占有された地域への移動を**攻撃**と呼ぶ。 |
| R-MOV-04 | 移動は、その戦力（1＋有効な支援数）が競合するすべての戦力 — 目的地にいるユニットの防御戦力（そのユニットが移動に成功して去らない場合）と、同じ目的地への他のすべての移動の戦力 — を**厳密に上回る**場合に成功する。 |

### 7.1 スタンドオフ（膠着）

| ID | ルール |
|----|--------|
| R-STD-01 | **同戦力:** 等しい（最大の）戦力を持つ2つ以上のユニットが同じ地域に入ろうとした場合、どれも移動しない。（ルールブック規則3） |
| R-STD-02 | **スタンドオフは撃退を起こさない:** 争われた地域に既にいるユニットは撃退されない。（規則4） |
| R-STD-03 | **渋滞:** 移動しない（維持する、または移動に失敗した）ユニットは、撃退されない限り、その地域へ移動しようとするユニットを阻み、これは連鎖する。（規則5） |
| R-STD-04 | **輸送なしの入れ替え不可:** 互いの地域へ移動し合う2ユニットは、両方とも移動することはできない。（規則6）支援付きの正面衝突は PR-01 参照。 |
| R-STD-05 | **回転:** 3つ以上のユニットは、直接入れ替わる2ユニットがない限り、回転移動（A→B→C→A）できる。（規則7） |
| R-STD-06 | **撃退されたユニットも他所でスタンドオフを起こす:** 撃退されたユニットは、攻撃者の出発地*以外*の地域でスタンドオフを引き起こし得る。（規則10） |
| R-STD-07 | **攻撃者の出発地には影響しない:** 撃退されたユニットは、たとえ支援を受けていても、自身を撃退した攻撃の出発地域には**一切影響しない**。その地域へ移動する別のユニットはそのユニットとスタンドオフしない。（規則11）正面衝突にのみ適用する: 輸送された攻撃で撃退されたユニットは、攻撃者の出発地で他のユニットとスタンドオフできる（PR-20）。 |

## 8. 支援

| ID | ルール |
|----|--------|
| R-SUP-01 | ユニットは移動の代わりに支援できる。支援には**攻撃的**（移動の支援）と**防御的**（維持・支援・輸送しているユニットの支援）がある。有効な支援1つにつき戦力 **+1**。 |
| R-SUP-02 | 支援するユニットは、**支援先の地域へ自分が合法に移動できる**必要がある（他ユニットの存在は無視）。支援されるユニットと隣接している必要はない。例: ブレストの陸軍はイギリス海峡へ支援できない。ローマの艦隊はヴェネツィアへ支援できない。 |
| R-SUP-03 | 分割海岸の地域のどちらかの海岸に到達できる艦隊は、**海岸に関係なく**その地域への移動を支援できる。支援で指定した海岸は確認しない（PR-18）。 |
| R-SUP-04 | 支援はどの列強のユニットにも、**同意なしに与えることができ、拒否できない**（ただし R-SLF-01/02 参照）。 |
| R-SUP-05 | **維持支援:** 移動を命じられていないユニット（維持・支援・輸送・無命令）は、その地域名のみを指定した支援（`S F Bal`）で支援できる。そのユニットが実際には移動しようとした場合、支援は無効。（規則8） |
| R-SUP-06 | **移動支援:** 支援する移動と完全に（出発地・目的地とも）一致しなければならない。支援対象が別の地域へ移動した、または維持した場合、支援は失敗し、維持支援には**変わらない**。（規則9） |
| R-SUP-07 | 支援は輸送できない。 |

### 8.1 支援カット

| ID | ルール |
|----|--------|
| R-CUT-01 | 支援しているユニットが、**支援先の地域以外のいずれかの地域から攻撃された場合、支援はカットされる**。攻撃の成否は問わない。カットされた支援は何も加えない。（規則13） |
| R-CUT-02 | **支援しているユニットが撃退された場合、支援はカットされる**。支援先の地域からの攻撃による撃退も含む。（規則14） |
| R-CUT-03 | 自身が撃退されつつあるユニットでも、他所の支援をカットできる（撃退してくる攻撃が、そのユニットの攻撃先から来ていない限り）。（規則15） |
| R-CUT-04 | **列強が自国ユニットを攻撃しても支援はカットされない。**（規則16） |
| R-CUT-05 | 輸送による攻撃の例外: R-CVY-09、R-CVY-10。 |

> ルールブックの助言: 複雑な局面では、まずどの支援がカットされるかを確定させてから移動を解決するとよい。

## 9. 輸送

| ID | ルール |
|----|--------|
| R-CVY-01 | 輸送できるのは**海域にいる艦隊**のみ。沿岸地域（キール、コンスタンティノープル、デンマークを含む）にいる艦隊は輸送できない。 |
| R-CVY-02 | 輸送できるのは**陸軍**のみ。艦隊は輸送できない。 |
| R-CVY-03 | 陸軍は、沿岸地域から、**それぞれに輸送する艦隊がいる隣接海域の連鎖**を通って、最後の艦隊に隣接する沿岸地域まで、1ターンで輸送できる。 |
| R-CVY-04 | 両方の命令が必要: 陸軍は目的地への移動を命じ、各艦隊は `C A <出発>-<到着>` を命じる。輸送命令は陸軍の移動と完全に一致しなければならず、一致しなければ輸送は失敗し陸軍はその場に留まる。1艦隊が1ターンに輸送できる陸軍は1つまで。 |
| R-CVY-05 | **輸送の妨害:** 経路に必要な輸送艦隊が**撃退された**場合、輸送は失敗し陸軍はその場に留まる。撃退に至らない攻撃は輸送に影響しない。（規則17） |
| R-CVY-06 | **目的地でのスタンドオフ:** 目的地でスタンドオフした輸送陸軍は出発地に留まる（そこで撃退されることはあり得る）。輸送陸軍は支援を受けられる。（規則18） |
| R-CVY-07 | **輸送による入れ替え:** 一方または両方が輸送される場合、2ユニットは位置を入れ替えられる。（規則19、R-STD-04 の例外） |
| R-CVY-08 | **複数経路:** 命令が複数の輸送経路を提供している場合、**少なくとも1経路**が健在なら陸軍は到着する。（規則20） |
| R-CVY-09 | **輸送による攻撃は特定の支援をカットしない:** 輸送陸軍は、その輸送に**必要な**艦隊への攻撃を支援しているユニットの支援をカット**しない**。（規則21、R-CUT-01 に優先） |
| R-CVY-10 | **…ただし別経路が成功する場合を除く:** 少なくとも1つの輸送経路が成功している陸軍は、目的地にいるユニットの支援を、それが別経路上の艦隊への攻撃支援であっても**カットする**。（規則22、R-CVY-09 に優先） |
| R-CVY-11 | **陸路と輸送経路**（陸軍がどちらでも目的地に到達できる場合）: 輸送艦隊のうち**少なくとも1つが陸軍の所有者のもの**なら輸送を使う。1つもなければ**陸路**を使う。ただし陸軍の命令に **"via convoy"（輸送経由）** と明記されていれば輸送を使う。（他国による陸軍の「誘拐」を防ぐ。） |

## 10. 自国ユニット撃退の禁止

| ID | ルール |
|----|--------|
| R-SLF-01 | **列強は自国ユニットを撃退することも、その撃退を支援することもできない**（意図しない場合でも）。そのような移動は撃退に失敗する（攻撃側は入れない）。（規則12） |
| R-SLF-02 | 列強 P が P 自身のユニットへの攻撃に与えた支援は、そのユニットの撃退には**算入されない**（図24）。攻撃側に*他の*支援が十分あれば、ユニットは撃退される。 |
| R-SLF-03 | 自国ユニットへの攻撃命令にも意味はある。例: スタンドオフを作る（図26）。 |
| R-SLF-04 | **自国スタンドオフ:** 列強は空き地域に自国ユニット2つを意図的にスタンドオフさせられる。一方が予期せず（自国・他国問わず）多くの支援を得た場合、その移動は成功する（図27）。その地域に自国ユニットが既にいる場合は成功しない。 |

## 11. 撤退・解散フェイズ

| ID | ルール |
|----|--------|
| R-RET-01 | 解決後、撃退された各ユニットは撤退するか解散する。撤退命令は交渉なしで書き、同時に公開する。 |
| R-RET-02 | 撤退先は、**そのユニットが通常移動できる隣接地域**でなければならない（艦隊の海岸ルールも適用）。撤退は輸送も支援もできない。 |
| R-RET-03 | 次の地域へは撤退**できない**: (a) 占有されている地域、(b) **攻撃者が来た地域**、(c) このターン**スタンドオフにより空いた地域**。 |
| R-RET-04 | 攻撃者の出発地から来た攻撃で、そこにスタンドオフしていた唯一のユニットが撃退されたために空いた地域（R-STD-07）は、スタンドオフ**ではない**ので撤退先に**できる**（図13/14）。 |
| R-RET-05 | 合法な撤退先がなければ、ユニットは**即座に解散**する。 |
| R-RET-06 | 2つ以上のユニットが同じ地域に撤退した場合、**すべて解散**する。 |
| R-RET-07 | 撤退命令のない撃退ユニットは解散する。撤退の代わりにいつでも自発的に解散できる。 |

## 12. 補給都市と調整（秋の後）

| ID | ルール |
|----|--------|
| R-SC-01 | **秋ターン終了時（撤退後）** に自国ユニットが補給都市を占有していれば、その列強が**支配権を得る**。 |
| R-SC-02 | 支配権は、各秋ターン終了時にその補給都市が空いているか所有者のユニットが占有している限り維持される。春に通過して秋に去っただけでは支配権は変わらない。 |
| R-ADJ-01 | 調整は交渉なしで書き、同時に公開する。曖昧・不正な調整命令は無視される。 |
| R-ADJ-02 | **解散:** ユニット数が補給都市数より多い列強は、超過分を解散しなければならない（どれを解散するかは所有者が選ぶ）。既定の選び方は内乱ルール参照。 |
| R-ADJ-03 | **建設:** 補給都市数がユニット数より多い列強は、**自らがまだ支配している空いた本国補給都市**1つにつき1ユニットを建設できる。本国補給都市以外には建設できない。 |
| R-ADJ-04 | 内陸の補給都市: 陸軍のみ。沿岸の補給都市: 種別を指定する。サンクトペテルブルクに艦隊を建設する場合は海岸（北岸/南岸）も指定する。 |
| R-ADJ-05 | 支配している本国補給都市がすべて占有されていれば、その年は建設できない（建設権は失われ、繰り越されない）。 |
| R-ADJ-06 | 本国補給都市をすべて失った列強も残りのユニットで戦い続けられるが、秋ターン終了時に本国補給都市を再び支配するまで建設できない。 |
| R-ADJ-07 | 列強は権利のある建設を**放棄**できる。 |
| R-ADJ-08 | ユニットも補給都市もない列強は脱落する。*（暗黙のルール。PR-10 参照。）* |

## 13. 内乱（統治崩壊）

| ID | ルール |
|----|--------|
| R-CD-01 | 春または秋ターンにゲームを離脱した、または命令を提出しなかった列強は**内乱**状態となる: 全ユニットが維持し、互いに支援**しない**。*（本ツールでは内乱は GM が宣言する — PR-16。）* |
| R-CD-02 | 撃退されたユニットは解散する（撤退しない）。建設は行わない。 |
| R-CD-03 | ユニットを減らす必要がある場合、**本国から最も遠いユニット**から解散する。同距離なら**艦隊を陸軍より先**に、次に**地域名のアルファベット順**。（距離の定義: PR-08。） |
| R-CD-04 | 離脱したプレイヤーの交代が推奨される。方針はゲーム開始前に決めておく。 |
